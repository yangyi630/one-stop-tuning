# 系统性能调优助手

一款面向 Windows 用户的系统性能优化工具，通过一键优化、垃圾清理、启动项管理、进程监控等功能，让电脑重获新生。

## 快速开始

### 方法一：双击启动（推荐）

1. 双击 `启动.bat` 文件
2. 程序会自动检查并安装所需依赖
3. 等待安装完成后，程序将自动启动

### 方法二：手动启动

1. 确保已安装 Python 3.8+
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行程序：
   ```bash
   python main.py
   ```

## 功能介绍

### 📊 仪表盘
- 系统硬件信息概览
- 实时系统评分

### 📈 性能监控

### 🎮 游戏模式

## 系统要求

- 操作系统：Windows 10/11
- Python 版本：3.8 或更高
- 管理员权限：部分功能需要管理员权限

## 注意事项

1. **首次运行**：部分优化功能需要管理员权限，请以管理员身份运行
2. **数据安全**：清理功能会永久删除文件，请谨慎操作
3. **效果验证**：游戏模式可作为系统优化效果的直观验证

## 常见问题

**Q: 点击启动.bat后没反应？**
A: 请确保已安装 Python，并将其添加到系统 PATH 环境变量

**Q: 提示缺少xxx模块？**
A: 重新运行 `启动.bat`，程序会自动安装缺失的依赖

**Q: 游戏模式需要管理员权限？**
A: 是的，游戏启动器功能需要管理员权限才能正常运行
